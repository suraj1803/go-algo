# Go Algorithms (goalgo)

## Project Structure

```text
goalgo/
├── go.mod
├── main.go                     # Entry point demonstrating algorithm usage
├── datastructures/             # Custom data structures (heaps, trees, queues, stacks, etc.)
├── dp/                         # Dynamic programming problems & algorithms
├── graph/                      # Graph algorithms & representations
│   ├── graph.go                # Graph structure and adjacency methods
│   ├── bfs.go                  # Breadth-First Search implementation
│   └── bfs_test.go             # Unit tests and benchmarks
├── math/                       # Mathematical & number-theoretic algorithms
├── searching/                  # Searching algorithms
│   ├── binary_search.go
│   └── binary_search_test.go
├── sorting/                    # Sorting algorithms
│   ├── quicksort.go
│   └── quicksort_test.go
└── strings/                    # String pattern matching & manipulation
```

## Running & Testing

### Run Demos
```bash
go run main.go
```
